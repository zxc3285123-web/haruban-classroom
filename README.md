# 하루반 · 학급 운영 수첩

교사를 위한 학급 운영 페이지입니다. 별도 설치나 빌드 없이 사용하는 정적 웹사이트입니다.

## 기능

- 학년도별 학급 정보와 학생 기록 관리
- 할 일과 카테고리, 일정과 반복 시간표
- 학생 정보, 지원 정보, 관찰 기록, 보호자 연락 기록
- 출결 관리와 엑셀 내려받기
- 엑셀(.xlsx) 양식으로 학생 일괄 추가 및 미리보기
- 제출·준비물, 예산·물품, 자료 링크
- 학년도별 백업과 복원

## 내 컴퓨터에서 실행

Python 3이 있는 환경에서 저장소 폴더를 열고 실행합니다.

```sh
python3 -m http.server 8000 --directory dist
```

브라우저에서 http://localhost:8000 을 엽니다. 배포할 때는 `dist` 폴더를 정적 사이트로 제공합니다.

## 기록 저장 방식

학생 기록은 사용하는 브라우저의 로컬 저장소에 저장됩니다. 이 저장소에는 실제 학생 기록이나 백업 파일을 넣지 않습니다. GitHub에 소스를 올려도 학생 기록이 동기화되지는 않습니다.

브라우저·기기·사이트 주소가 달라지면 저장된 기록이 자동으로 옮겨지지 않습니다. 이전 사이트의 설정·백업에서 필요한 기록을 내려받고 새 주소에서 복원하세요. 브라우저 데이터를 지우기 전에도 백업하세요.

## 파일 구성

- `dist/`: 웹사이트 실행 파일
- `tests/`: 일정 관련 검증
- `.openai/hosting.json`: 기존 Sites 배포 설정

## 확인

Node.js가 있는 환경에서 실행합니다.

```sh
node --test tests/planner.test.cjs
```

JSZip은 `dist/vendor/`에 포함되어 있으며 해당 폴더에 라이선스가 있습니다.
